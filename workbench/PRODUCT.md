# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

The Oczy researcher evaluating scoped learning, knowledge preservation, language
interfaces and tool execution. This record applies only to the local workbench.

## Product Purpose

Package the current experiment, previous regression checks and an inspectable
trial experience, as requested in the current task.

## Operating Context

Local DEV research. Existing findings use `docs/oczy_findings.html`. The workbench
extends that evidence-reading workflow with bounded exploratory comparisons.

## Capabilities and Constraints

Frozen evaluations remain authoritative. Live inputs never update training or
scores. All three seeds remain visible. Retrieval and externally supplied rules
are explicit comparisons. Tool transcripts must show real filesystem outcomes.
Model weights and runtime are separate from the portable source/evidence bundle.

## Open Implementation Decisions

The interactive workbench plus CLI was proposed through an optional question.
No reply was received before implementation. Plain HTML/CSS/JavaScript and a
standard-library Python local server are this task's implementation assumption,
not a stored user preference for future products.

## Evidence on Hand

Versioned manifests and audited local DEV result JSON under `experiments_logs/`.
No claims about meta-test performance, deployed learning or general agent
reliability are authorized by this evidence.
