# Capability regression DEV v1

Authorized by the user's request to check previous objectives against regression.
Frozen before model calls. No instrument, threshold, previous result or checkpoint
is changed. All three final diversity states are tested, with old matched controls,
initial states and zeroed state. There is no optimizer or meta-test access.

The replay contains 708 historical capability/persistence rows, 32 direct-operation
language cases, and 64 qualified decoder comparisons. Complete historical row
equality is required, including raw output, score, prompt hash and action outcomes.
Reproducing a failure is regression integrity evidence, not a capability pass.

The candidate receives 160 unchanged v1 stage-2 probes across ten numeric conditions
and 48 real temporary-filesystem action trials including retrieval controls. These
are robustness checks of a joint learner, not proof of sequential accumulation or
correction. The older action prompt is intentionally preserved, including its
known final-answer placeholder defect. Tool sequence, actual files and final text
remain separate outcomes. Composition requires separately correct components.

Historical workers are reused in one fresh offline process. This is a read-only
behavioral replay, not a repeat of the original phase-isolated training experiment.
Execution verifies the pinned model/runtime, every registered source/input hash,
candidate provenance, zero optimizer steps and an unchanged organ before/after.
