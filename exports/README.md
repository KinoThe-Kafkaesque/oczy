The 3.4 MB bundle contains 607 sealed files plus its manifest. After unpacking,
run `python -m workbench verify` and `python -m workbench serve` inside
`oczy-workbench/`. Saved evidence uses Python's standard library. Live trials
need the separately configured pinned runtime and model; neither is downloaded
or included. The existing research workstation configuration was tested.

The unpacked bundle's real seven-condition CLI comparison exactly matches the
repository CLI and browser trial. Historical regression is 804/804 exact
reproductions, including old failures. New scoped-learning performance remains
partial; the package is an inspectable research experience, not capability
acceptance. The post-evaluation controller bookkeeping recovery is disclosed.
